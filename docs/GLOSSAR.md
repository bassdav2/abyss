# Glossar · Version 1.7

Seit 1.7 verwendet das Spiel einfache Begriffe, wie sie Spielerinnen und Spieler kennen. Frühere Bezeichnungen stehen in Klammern, weil sie in älteren Berichten und im Code noch vorkommen (Klassennamen wie `Item`, `ActiveModule` oder `repairKits` bleiben unverändert).

| Begriff | Bedeutung in ABYSS |
|---|---|
| Tauchgang / Run | Ein Versuch vom Heck bis zur Brücke; nach einem Sieg optional weitere Durchläufe |
| Durchlauf (früher Zyklus) | Erneuter Weg durch alle 24 Räume mit bisherigem Build und stärkeren Gegnern |
| Schwierigkeit (früher Druckstufe) | Wählbarer Schwierigkeitsgrad 0–5; ein Sieg schaltet die nächste Stufe frei |
| Sektion | Hecksektion, Maschinendeck, Forschungsdeck, Kommandodeck (je sechs Räume) |
| Raumposition / Tiefe | Fortschritt im Durchlauf; intern 0–23, sichtbar 1–24 |
| Raumthema | Fachliche Identität eines Raums (z. B. Torpedomagazin, Sauerstoffgarten) |
| Raumzustand | Besondere Regel eines Kampfraums: Stromausfall, Alarmstufe Rot, Druckleck, Hüllenbruch, Schlagseite – jeweils mit Ausgleich |
| Raumtechnik | Eingebaute Anlagen: Förderband, Dampfdüse, Turbinenwind, Hydraulikpresse, Lasergitter, Notschalter |
| Notschalter | Konsole, die auf E einen Sektionseffekt auslöst: Torpedo, Dampfventil, Kältekammer oder Überlast |
| Eskalation | Ab Raum 20 steigt sie mit jedem Raum: grössere Schwärme, breitere Räume, mehr Elitegegner |
| Bedrohung | Prüfung für den Build in einem Kampfraum (z. B. Panzerschwarm, Flutwelle, Luftschlag) |
| Schmugglerdrohne | Fliehender Gegner mit Beute; entkommt nach 15 Sekunden |
| Bordsystem | Die im Pixelbild gezeichnete Menüoberfläche (Schottplatten, Terminals, Hologramm-Karten) |
| Route / Abzweig | Folge gewählter Räume; an Wahlpositionen zwei Angebote |
| Seed | Ganze Zahl, aus der Route, Räume und Angebote reproduzierbar entstehen |
| Laufsteg | Einseitig begehbare Plattform; von unten durchspringbar, mit S + Sprung durchfallbar |
| Leben (früher Integrität) | Lebenspunkte; bei null endet der Tauchgang (ausser Notfallkapsel) |
| Energie | Ressource für Fähigkeiten; regeneriert sich, Abschüsse laden nach |
| Schild | Energieschild aus Schildzellen; fängt Schaden vor dem Leben ab |
| Medkit (früher Reparaturset) | Heilt auf Q 35 Leben |
| Schrott | Run-Währung für Schwarzmarkt und Werkstatt |
| Kerne (früher Datenkerne) | Dauerhafte Währung zum Freischalten; von Elitegegnern, Bossen und langen Tauchgängen |
| XP und Level-Up (früher Überladung und Levelaufstieg) | Energiesplitter füllen die XP-Leiste; ist sie voll, steht die Zeit still und du wählst ein Upgrade |
| Klasse | Spielbare Taucherin/Taucher mit Werten, Eigenheit und Startausrüstung |
| Waffe | Primärangriff mit Kombination, Luftangriff und Waffenstufe aus der Werkstatt |
| Fähigkeit (früher aktives Modul) | Aktion auf K, z. B. Schildimpuls oder Kryogranate |
| Upgrade (früher passives Modul) | Verbesserung im laufenden Run, Seltenheit Standard, Selten, Legendär, Verflucht oder Evolution; stapelbar |
| Evolution (früher Entfesselung) | Ausgereiztes Upgrade plus Partner ergibt beim nächsten Level-Up eine stärkere Form |
| Synergie (früher Resonanz) | Paar von Upgrades, das zusammen einen Zusatzbonus freischaltet |
| Build | Kombination aus Klasse, Waffe, Upgrades und Ressourcen |
| Beute (früher Bergung) | Belohnung nach einem gesicherten Raum: Wahl aus drei bis vier Angeboten in der Beutekapsel |
| Schwarzmarkt | Händlerin, die Upgrades und Versorgung gegen Schrott verkauft |
| Werkstatt | Gratis heilen, günstige Upgrades, Medkits, Waffenstufen |
| Schrein (früher Druckkapelle) | Altar mit Handeln: Opfer gegen Belohnung, teils verfluchte Upgrades |
| Welle / Patrouille | Gegnergruppe; Räume haben eine bis vier Wellen, dazu Schwärme |
| Elite / Affix | Stärkerer Gegner mit Eigenschaft (Gepanzert, Instabil, Flink, Selbstreparatur, Schildgenerator) |
| Boss (früher Sektorwächter) | Schottmeister, Reaktorkern, Brutmutter, Lotse, ab dem zweiten Durchlauf die Prismenkaiserin; drei Phasen, keine lässt sich überspringen |
| Deckung | Der Lotse blockt fast allen Schaden; nur in seinen Pausen nach einem Muster dringt ein Teil durch |
| Vorwarnung / Telegraph | Sichtbares Signal vor einem Angriff (Zielstrahl, Bodenzone, Kreis, Strahl, Säule, Warnlinie) |
| Zustand | Brand, Kälte, Frost, Markierung, Schock |
| Spielstand / Checkpoint (früher Raum-Sicherung) | Unveränderlicher Zustand am Raumeingang |
| Profil | Statistik, Kerne, Freischaltungen, Sammlung, Aussehen, letzte Vorbereitung, Einstellungen |
| Freischalten (früher Archiv) | Menü für dauerhafte Freischaltungen, Sammlung, Erfolge und Synergien |
| Sammlung (früher Kompendium) | Alle entdeckten Upgrades, unentdeckte als Silhouette |
| Erfolge (früher Logbuch) | Liste dauerhafter Ziele; jedes bringt beim ersten Erreichen Kerne |
| Talente (früher Laufbahn) | Skill-Bäume mit dauerhaften Rängen für das Konto und jede Klasse |
| Vorbereitung (früher Schleuse) | Wahl von Klasse, Waffe, Fähigkeit und Schwierigkeit vor dem Tauchgang |
| Tagestauchgang | Tauchgang mit Seed aus dem Datum (JJJJMMTT); am selben Tag für alle gleich |
| Aussehen (früher Garderobe) | Anzugfarbe, Helmform, Visierfarbe, Metallton der Figur |
| Entdecker | Zugänglicherer Modus: mehr Leben, mehr Schaden, weniger erlittener Schaden |
| Trefferpause | Sehr kurzes Anhalten der Simulation bei Treffern, rein zur Rückmeldung; höchstens etwa 4 % der Spielzeit |
| Bordaudio | Synthesizer und Effektmischer im Spiel; erzeugt die Musik zur Laufzeit |
| Framebuffer | Pixelbild 480 × 270, in das die Welt gezeichnet wird; Oberfläche auf einer Ebene mit 960 × 540 |
