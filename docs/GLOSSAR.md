# Glossar

| Begriff | Bedeutung in ABYSS |
|---|---|
| Tauchgang / Run | Ein Versuch vom Heck bis zur Brücke; kann nach einem Sieg in weitere Zyklen übergehen |
| Zyklus | Ein erneuter Weg durch zwölf Raumpositionen mit bisherigem Build und begrenzt erhöhter Schwierigkeit |
| Sektion | Einer der drei Bereiche: Heck, Maschinenbereich, Kommando |
| Raumposition / Tiefe | Fortlaufender Fortschritt im Zyklus; intern 0-11, sichtbar 1-12 |
| Route / Zweig | Folge der gewählten Raumangebote; an bestimmten Positionen genau ein, sonst zwei Angebote |
| Seed | Ganze Zahl als Ausgangspunkt reproduzierbarer Raum- und Beuteangebote |
| Integrität | Lebenspunkte der Spielfigur; bei null endet der Run |
| Energie | Ressource für das aktive Modul; regeneriert sich |
| Schrott | Lokale Run-Währung; unter anderem für Werkstattmodule |
| Aktives Modul | Gewählte Sonderfähigkeit: Schildimpuls, Lichtbogen oder Druckschild |
| Passives Modul | Dauerhafte Verbesserung innerhalb des aktuellen Runs; sechs Typen, je bis zu drei Stufen |
| Build | Kombination aus aktivem Modul, passiven Modulen und Ressourcen im aktuellen Run |
| Bauplan | Permanente Freischaltung einer alternativen Startfähigkeit |
| Patrouille / Welle | Eine Gegnergruppe; ein Raum kann mehrere nacheinander enthalten |
| Telegraph / Vorwarnung | Sichtbares Signal vor einem feindlichen Angriff oder einer Gefahr |
| Raum-Sicherung / Checkpoint | Unveränderlicher Zustand am Raumeingang; kein beliebiger Moment mitten im Kampf |
| Profil | Dauerhafte Baupläne, Statistik und Einstellungen |
| Der Lotse | Automatischer Wächter der Brücke und Abschlussgegner |
| Entdecker | Zugänglicherer Spielmodus mit mehr Start-Integrität und höherem Basisschaden |

- **Schottmeister:** erster Sektorwächter, Raum 5.
- **Reaktorkern:** zweiter Sektorwächter, Raum 11.
- **Vorratskiste:** zerstörbarer Fund mit Reparaturgel, Energiezelle oder Ersatzteilen.
- **Bootskarte:** pausierende Übersicht der 18 Raumpositionen; Hauptweg-Vorschau und bisherige eigene Route.
