# Glossar · Version 1.0

| Begriff | Bedeutung in ABYSS |
|---|---|
| Tauchgang / Run | Ein Versuch vom Heck bis zur Brücke; nach einem Sieg optional weitere Zyklen |
| Zyklus | Erneuter Weg durch alle 24 Räume mit bisherigem Build und stärkeren Gegnern |
| Druckstufe | Wählbarer Schwierigkeitsgrad 0–5; ein Sieg schaltet die nächste Stufe frei |
| Sektion | Hecksektion, Maschinendeck, Forschungsdeck, Kommandodeck (je sechs Räume) |
| Raumposition / Tiefe | Fortschritt im Zyklus; intern 0–23, sichtbar 1–24 |
| Raumthema | Fachliche Identität eines Raums (z. B. Torpedomagazin, Sauerstoffgarten) |
| Raumzustand | Besondere Regel eines Kampfraums: Stromausfall, Alarmstufe Rot, Druckleck, Hüllenbruch, Schlagseite – jeweils mit Ausgleich |
| Raumtechnik | Eingebaute Anlagen: Förderband, Dampfdüse, Turbinenwind, Hydraulikpresse, Lasergitter, Notschalter |
| Notschalter | Konsole, die auf E einen Sektionseffekt auslöst: Torpedo, Dampfventil, Kältekammer oder Überlast |
| Hüllenbruch | Raumzustand: 40 Sekunden überleben, Gegner strömen nach, Wasser steigt |
| Schlagseite | Raumzustand: Das Boot krängt alle 11 Sekunden, alles rutscht, Trümmer fallen |
| Schmugglerdrohne | Fliehender Gegner mit Beute; entkommt nach 15 Sekunden |
| Bordsystem | Die im Pixelbild gezeichnete Menüoberfläche (Schottplatten, Terminals, Hologramm-Karten) |
| Route / Abzweig | Folge gewählter Räume; an Wahlpositionen zwei Angebote |
| Seed | Ganze Zahl, aus der Route, Räume und Angebote reproduzierbar entstehen |
| Laufsteg | Einseitig begehbare Plattform; von unten durchspringbar, mit S + Sprung durchfallbar |
| Integrität | Lebenspunkte; bei null endet der Tauchgang (ausser Notfallkapsel) |
| Energie | Ressource für aktive Module; regeneriert sich, Abschüsse laden nach |
| Schild | Energieschild aus Schildzellen; fängt Schaden vor der Integrität ab |
| Schrott | Run-Währung für Schwarzmarkt und Werkstatt |
| Datenkern | Dauerhafte Währung im Archiv; von Elitegegnern, Wächtern und langen Tauchgängen |
| Klasse | Spielbare Taucherin/Taucher mit Werten, Eigenheit und Startausrüstung |
| Waffe | Primärangriff mit Kombination, Luftangriff und Werkstattstufe 0–3 |
| Aktives Modul | Fähigkeit auf K, z. B. Schildimpuls oder Kryogranate |
| Passives Modul / Item | Verbesserung im laufenden Run, Seltenheit Standard, Selten, Legendär oder Verflucht |
| Build | Kombination aus Klasse, Waffe, Modulen und Ressourcen |
| Resonanz | Paar passiver Module, das zusammen einen Zusatzbonus freischaltet |
| Bergung / Bergungskapsel | Belohnung nach einem gesicherten Raum: Wahl aus drei bis vier Angeboten |
| Schwarzmarkt | Händlerin, die Module und Versorgung gegen Schrott verkauft |
| Werkstatt | Kostenlose Reparatur, günstige Module, Reparatursets, Waffenstufen |
| Druckkapelle | Altar mit Handeln: Opfer gegen Belohnung, teils verfluchte Module |
| Welle / Patrouille | Gegnergruppe; Räume haben eine bis drei Wellen |
| Elite / Affix | Stärkerer Gegner mit Eigenschaft (Gepanzert, Instabil, Flink, Selbstreparatur, Schildgenerator) |
| Sektorwächter / Boss | Schottmeister, Reaktorkern, Brutmutter, Lotse; drei Phasen, Panzerung ausser in der Erholung |
| Vorwarnung / Telegraph | Sichtbares Signal vor einem Angriff (Zielstrahl, Bodenzone, Kreis, Strahl, Säule) |
| Zustand | Brand, Kälte, Frost, Markierung, Schock |
| Raum-Sicherung / Checkpoint | Unveränderlicher Zustand am Raumeingang |
| Profil | Statistik, Datenkerne, Freischaltungen, Kompendium, Aussehen, letzte Vorbereitung, Einstellungen |
| Archiv | Menü für dauerhafte Freischaltungen, Kompendium und Logbuch |
| Logbuch | Liste dauerhafter Ziele; jedes bringt beim ersten Erreichen Datenkerne |
| Tagestauchgang | Tauchgang mit Seed aus dem Datum (JJJJMMTT); am selben Tag für alle gleich |
| Garderobe | Anzugfarbe, Helmform, Visierfarbe, Metallton der Figur |
| Entdecker | Zugänglicherer Modus: mehr Integrität, mehr Schaden, weniger erlittener Schaden |
| Trefferpause | Sehr kurzes Anhalten der Simulation bei Treffern, rein zur Rückmeldung |
| Framebuffer | Pixelbild 480 × 270, in das die Welt gezeichnet wird |
